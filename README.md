
# Proyecto: Máquina Adivina Pensamientos

Descripción:
Este proyecto está desarrollado en Java 8.1 (o versión cercana) y consiste en la creación de una máquina cuya función principal es adivinar pensamientos o series. La máquina realiza una serie de preguntas predefinidas al usuario para, con base en sus respuestas, identificar lo que está pensando.

La lógica del programa se basa en un conjunto de preguntas y posibles respuestas que guían la adivinanza hacia un resultado específico.

# Características
Implementación en Java 8.1.

Interacción sencilla con el usuario mediante consola.

Preguntas predefinidas que permiten deducir el pensamiento o serie.

Uso de estructuras condicionales para la lógica de adivinanza.

# Requisitos
Java JDK 8 o superior instalado en el sistema.

Un IDE para Java o acceso a la terminal para compilar y ejecutar el programa.

# Cómo ejecutar
Clona o descarga el repositorio.

Navega a la carpeta del proyecto.

Compila el código fuente:

# Ejecuta
javac NombreArchivo.java
Ejecuta el programa:

# Ejecuta
java NombreArchivo

# Uso
Al ejecutar, la máquina realizará una serie de preguntas en la consola. El usuario debe responder según lo solicitado y al finalizar, la máquina intentará adivinar el pensamiento o la serie.
